# Simulating a strategy

Use the backtest.py script to simulate a startegy. It's usage is documented in the CLI Workflows section of the README.md file. 

If start_date is not specified, assume 2020-01-01. 

if end_date is not specified, assume the last day for which underlying data is available in the /md database. 

if underlying is not specified, assume ^IXIC. 

look for strategy definition files in strategies folder. 

If overrides for strategy parameter are specified, use them as command line argument overrides for the backtest.py script. 

Place output in the out folder, come up with a descriptive name. 

Display the performance statistics generated by backtest.py as stdout output as part of your answer.
